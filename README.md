# Medical Appointment Booking

Medical Appointment Booking is a React application for finding healthcare professionals, booking appointments, requesting instant consultations, and sharing doctor reviews.

## Setup Instructions

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Install the dependencies:

	```bash
	npm install
	```

4. Start the development server:

	```bash
	npm start
	```

5. Open `http://localhost:3000` in a browser.

## Available Features

- Search for doctors by speciality.
- Book a consultation with a doctor.
- Request an instant consultation with Name and Phone Number.
- Sign up and log in through the authentication API.
- Submit a doctor review and receive a submitted confirmation.
- View appointment notifications throughout the application.

## Production Build

Run `npm run build` to create the optimized production files in the `build` directory.
